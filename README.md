# FitQuest

In order to run this project: 

1. download zip or clone repository
2. open in editor
3. run npm i for both Client and Server Folder dependencies
4. replace .env.example file with .env file that has given credentials in report
5. to run client side: npm run dev
6. to run server side: Node server.js
7. click given link:  http://localhost:5173/ or paste into browser
